# mwar's AI Playground

Кроссплатформенный AI-клиент и игровая песочница на базе **Godot 4.7** (Desktop & Android). Приложение объединяет в одном интерфейсе стриминговый AI-чат, движок процедурных текстовых RPG-квестов с картой мира и живую песочницу, где нейросеть пишет и сразу запускает мини-игры на GDScript.

## Основные возможности

### 💬 AI-чат
* **Стриминг в реальном времени** с подсчётом скорости, токенов и заполнения контекста (`32k`).
* **Режим рассуждений:** переключение между `⚡ Быстро` (`/no_think`) и `🧠 С мыслями` с отображением сворачиваемого блока размышлений (`<think>` / `reasoning_content`).
* **Очередь сообщений:** можно отправлять следующие сообщения, не дожидаясь завершения текущего ответа.

### 🎲 Текстовые RPG-квесты с картой мира
* **Генерация кампаний** по собственному сеттингу или готовым пресетам с настройкой сложности, числа актов, количества локаций и режима пермасмерти.
* **Интерактивная графовая карта мира:** отображает открытые, посещённые и смежные локации, поддерживает зум и перемещение по клику.
* **Гибридный движок (`QuestEngine`):** скриптовые действия и переходы между комнатами работают мгновенно и без траты токенов, а нестандартные действия обрабатывает AI-Гейммастер.
* **Фоновый «Архитектор мира»:** автоматически проектирует следующие акты и локации в фоне по мере прохождения.
* **Инвентарь и характеристики:** отслеживание HP, времени/кислорода, ресурсов и предметов.
* **Сохранение и экспорт:** экспорт готовых сценариев в `.json`, сохранение/загрузка сессий, автосохранение при выходе и восстановление прерванной генерации при перезапуске.

### 🎮 Песочница мини-игр (AI → GDScript)
* В режиме игры до старта квеста любой текстовый запрос генерирует **рабочую мини-игру или виджет на GDScript** прямо внутри приложения (`GDScript.new()`).
* **Интерактивное редактирование:** игру можно дорабатывать новыми промптами на лету.
* **Авто-ремонт кода:** встроенный санитайзер типичных ошибок LLM и до 5 автоматических попыток исправления при ошибках компиляции.
* **Вкладки `Игра / Чат / Код`** и сохранение созданных мини-игр в `.json`.

## Поддерживаемые AI-провайдеры

Провайдер определяется автоматически по URL:
* **Локальные:** Ollama (`http://localhost:11434/v1` или локальный IP)
* **Облачные:** OpenAI, OpenRouter, DeepSeek, Groq, Together, Mistral, Anthropic (Claude), Google Gemini, f5ai и любые OpenAI-совместимые API.

Есть история адресов и моделей с автоподстановкой последней выбранной модели для каждого сервера.

## Установка и запуск

1. Скачайте сборку для вашей платформы со страницы [**Releases**](../../releases):
   * **Windows:** распакуйте `mwai_godot-windows-*.zip` и запустите `mwai_godot.exe`.
   * **Linux:** распакуйте `mwai_godot-linux-*.zip` и запустите `mwai_godot.x86_64`.
   * **Android:** установите `mwai_godot-android-*.apk`.
2. Откройте панель настроек в верхней панели (статус-бар), укажите URL API (и ключ, если требуется) и нажмите **🔄 Обновить** для загрузки списка моделей.

### Запуск из исходников
* Требуется **Godot Engine 4.7+** (стандартная версия GDScript, без .NET).
* Клонируйте репозиторий и откройте `project.godot` в редакторе Godot.

## Примечания по безопасности
* Локальные настройки и API-ключ сохраняются в `user://settings.json`. При экспорте файла сессии будьте внимательны перед отправкой его третьим лицам — файл конфигурации сессии может содержать активный токен.
* В режиме **Песочницы** сгенерированный код GDScript выполняется нативно на движке Godot — запускайте сторонние сохранённые игры `.json` только из доверенных источников.
